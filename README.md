# JZMU-Final-Exam-Paper-Extraction
Fully generated by Qwen3.7, this tool is designed for extracting exam papers from JZMU's digital resource platform. It automatically extracts source files, renames them with titles, and appends missing file extensions. Tested on macOS Golden Gate, it should also work on Windows in theory. Intended solely for educational and communication purposes; users assume full responsibility for any issues arising from use, and its use for other purposes is strictly prohibited. Due to website stability concerns, logging into aTrust may be required. Supports time-based filtering.
